Shared Kanban with Tree ACLs

A real-time collaborative board built with zero custom backend servers. Demonstrates fine-grained Tree Path Ownership (boards/{id}/**) and stateless signed invites powered directly by JayDB Cloud.

🌳
Tree Path Ownership: Board creators own their subtree and can invite other users.
🔐
Stateless Delegation: Share boards with Read-Only or Read & Write access via signed links.
⚡
Zero S3 Calls for ACLs: Permissions evaluated in-memory with sub-millisecond latency.
